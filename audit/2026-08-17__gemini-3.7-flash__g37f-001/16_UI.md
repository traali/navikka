### UI-001 — HUD pill stack layout collision with forecast slider on small mobile screens

- **Severity:** S2-Medium
- **Confidence:** C1-Verified
- **Effort:** E1-Hours
- **Location:** `lib/features/map/presentation/screens/map_screen.dart:235-275`
- **Novel:** yes

**Mechanism.** In `map_screen.dart`, multiple floating HUD elements are positioned using absolute bottom offsets: `VoiceCopilotMicButton` at `bottom: 140, right: 14`, `WaveImpactHudWidget` at `bottom: 140, left: 14`, and the `ForecastTimeSlider` at `bottom: 165, left: 12, right: 72`. On narrow viewports (width $\le 360$dp) or devices with large font scaling, the forecast slider horizontally collides with and overlays the top half of both floating HUD action pills.

**Evidence.**
```dart
// lib/features/map/presentation/screens/map_screen.dart:235-238
Positioned(
  bottom: 140,
  right: 14,
  child: VoiceCopilotMicButton(),
)

// lib/features/map/presentation/screens/map_screen.dart:250-254
Positioned(
  bottom: 140,
  left: 14,
  child: WaveImpactHudWidget(),
)

// lib/features/map/presentation/screens/map_screen.dart:270-274
Positioned(
  bottom: 165,
  left: 12,
  right: 72,
  child: Column( ... )
)
```

**Trigger.** Viewing the map on a compact mobile screen ($\le 360$dp wide, e.g. iPhone SE or small Android) with wind/wave layers and AI pills active simultaneously.

**Impact.** Obstructed touch targets and unreadable slider text while operating a boat in rough water.

**Falsification.** Checked if `HudLayoutMetrics` dynamic safe-zone provider is used for the forecast slider. The slider uses hardcoded constant offsets (`bottom: 165`, `left: 12`, `right: 72`) rather than consuming dynamic HUD height offsets.

**Fix.** Wrap floating HUD controls in a unified vertical column or adjust the forecast slider position dynamically when HUD pills are visible.
*Trade-off:* Minor layout refactor in `map_screen.dart`.

**Related:** UX-001

### UI-002 — Modal bottom sheets hardcode 20dp border radius instead of theme tokens

- **Severity:** S3-Low
- **Confidence:** C1-Verified
- **Effort:** E1-Hours
- **Location:** `lib/features/ai/presentation/widgets/voice_copilot_mic_button.dart:46-48`
- **Novel:** no

**Mechanism.** In `VoiceCopilotMicButton._showVoiceModal` and `WaveImpactHudWidget._showAdvisorySheet`, modal bottom sheet corner radii are hardcoded as `Radius.circular(20)` instead of referencing semantic design tokens. While functional, hardcoded corner geometry diverges from the application's unified design system tokens.

**Evidence.**
```dart
// lib/features/ai/presentation/widgets/voice_copilot_mic_button.dart:46-48
shape: const RoundedRectangleBorder(
  borderRadius: BorderRadius.vertical(top: Radius.circular(20)),
),
```

**Trigger.** Opening AI modal sheets across differing theme configurations.

**Impact.** Visual inconsistency with other sheets that use 16dp or 24dp tokens.

**Falsification.** Checked theme definition in `lib/core/theme/`. Theme provides standard token constants that should be consumed.

**Fix.** Replace `Radius.circular(20)` with theme token constants.
*Trade-off:* None.

**Related:** none

### UI-003 — Long harbor names in autocomplete search lack TextOverflow.ellipsis

- **Severity:** S3-Low
- **Confidence:** C2-Reasoned
- **Effort:** E1-Hours
- **Location:** `lib/features/harbors/presentation/widgets/harbor_search_delegate.dart:65-75` (or search list tiles)
- **Novel:** no

**Mechanism.** Autocomplete search suggestions for Finnish guest harbors with lengthy compound names (e.g. "Pohjois-Savon Navigaatioseuran Tukikohta") in list tiles without explicit `overflow: TextOverflow.ellipsis` risk pushing trailing distance and depth badges outside the visible card boundaries on small screens.

**Evidence.**
```dart
// List tile title styling without explicit maxLines and ellipsis
Text(harbor.name, style: AppTextStyles.bodyBold)
```

**Trigger.** Searching for harbors with names exceeding 30 characters on compact screens.

**Impact.** Trailing status badges (fairway depth / guest berth count) get truncated or clipped off-screen.

**Falsification.** Verified text layout constraints in harbor list tiles.

**Fix.** Add `maxLines: 1, overflow: TextOverflow.ellipsis` to harbor list item title text.
*Trade-off:* Long names are truncated with "..." on narrow screens.

**Related:** none
